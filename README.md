# Todo List application

## Description
This is an application built to practice during the React 26.4 course at Code the Dream (CTD).

Work in progress...

## Installation Instruction

- Download repository using ``git clone`` or 'Download ZIp' option
- Run ``npm install`` from the root
- Run ``npm run dev`` to start server  

## Usage

Application will be started locally on port 5001: http://localhost:5001/

If you need to change port, update vite.config.js 
``
  server: {
    port: 5001
  }
``
